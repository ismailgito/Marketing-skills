## How to use

1. Choose the ZIP skill pack that matches the task.
2. Keep the archive intact and import or share it using your preferred workflow.
3. Combine packs when a project needs research, execution, measurement, and optimization.

## Design note

The README uses small looping pixel-art animations to represent the two core loops of performance marketing: **measure growth** and **execute campaigns**.
